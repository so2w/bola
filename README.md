# Retro Soccer 2D

Retro Soccer 2D (Bola clone) — Phaser 3 + Vite + TypeScript MVP.

## Prerequisites

- Node.js 18+
- npm

## Install

```bash
npm install
```

## Generate Assets

```bash
npm run gen:sprites
```

Assets are generated by `scripts/generate-sprites.js` and placed in `public/assets/`.

## Dev

```bash
npm run dev
```

Open http://localhost:5173

The game uses Vite dev server with Phaser 3 Arcade Physics.

## Build

```bash
npm run build
npm run preview
```

Production build outputs to `dist/`.

## Dev Notes

- Stack: Phaser 3.x, Vite, TypeScript, Arcade Physics
- Player 8-direction movement, animation state machine, charged shot
- Ball X/Y Arcade Physics with fictitious Z offset and shadow sync coming
- See `AGENTS.md` for architecture and subsystems
